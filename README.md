
# Local Map

Local Map is a simple local service discovery website that helps users find nearby service providers through an easy-to-use interface.

## Features

- Search for local service providers
- Browse available service categories
- View provider details
- Contact providers
- Responsive design for desktop, tablet, and mobile
- Simple and user-friendly interface

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
